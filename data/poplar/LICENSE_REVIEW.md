# Poplar data-use review

Status: **publicly downloadable; derived-archive redistribution not confirmed**.

The ORNL LabKey project exposes the chromosome GBZ files without authentication and
the accompanying README describes the graph release, but neither source states a
license for the data. The related Genes article is CC BY 4.0; that article license
does not by itself license the separately hosted graph files.

Until the dataset owner confirms reuse terms, the generated Chr19 `.pngr` may be
used for local validation only. Do not upload it to the public archive origin and do
not configure `PANGENOME_RANGE_DEMO_POPLAR_ARCHIVE_URL` in GitHub Pages.

Review sources:

- https://labkey.ornl.gov/labkey/CBI/Jacobson/PUBLIC_DATA/poplar_pangenome/pan_genome_graph/project-begin.view
- https://doi.org/10.3390/genes11080843
