# Chicken corpus license review

The graph is the `pangenome.gfa.gz` file deposited with Rice et al., *A
pangenome graph reference of 30 chicken genomes allows genotyping of large and
complex structural variants*, BMC Biology (2023).

- Zenodo record: <https://zenodo.org/records/10018222>
- Article: <https://doi.org/10.1186/s12915-023-01758-0>
- Zenodo file license: **Creative Commons Attribution 4.0 International
  (CC BY 4.0)**
- Required credit: retain the dataset citation and license when distributing
  the derived `.pngr` archive.

This review uses the license attached to the Zenodo file. The article's general
language about data does not override that explicit dataset license.

Gene annotations come from NCBI RefSeq assembly GCF_016699485.2 (GRCg7b).
NCBI states that it places no restrictions on use or distribution of molecular
data, while noting that submitters may retain rights. The demo acknowledges
NCBI and records the exact annotation file checksum.

The repository's MIT license applies to the software, not as a replacement
license for either upstream dataset.
